# P10914 跳石头 题解

## 思路

这道题主要有两个部分：倒序动态规划，以及用 `bitset` 维护集合。

### 1. 动态规划

设 $S_j$ 表示从第 $j$ 块石头出发，所有可能经过的石头的权值集合。

从 $j$ 出发，首先一定会经过 $j$ 本身；之后可以跳到 $2j$ 或者 $j+c_j$。因此有

$$
S_j=\{c_j\}\cup S_{2j}\cup S_{j+c_j},
$$

其中下标超过 $n$ 的集合视为空集。

因为 $c_j$ 是正整数，所以

$$
2j>j,\qquad j+c_j>j.
$$

也就是说，所有转移都从编号较小的石头指向编号较大的石头。因此按照 $n,n-1,\ldots,1$ 的顺序计算时，$S_j$ 所依赖的状态都已经求出。

最后的答案为

$$
\max_{1\le j\le n}|S_j|.
$$

### 2. 用 `bitset` 表示集合

权值满足 $1\le c_i\le n$，可以用一个长度为 $n$ 的二进制串表示权值集合：第 $v-1$ 位为 $1$，表示权值 $v$ 在集合中。

这样，集合操作可以直接转化为位运算：

- 加入权值 $c_j$：`f[j].set(c[j] - 1)`；
- 求两个集合的并：`f[j] |= f[next]`；
- 求集合大小：`f[j].count()`。

`bitset` 底层会按机器字进行运算。一次集合并或计数只需要处理约 $n/64$ 个 64 位整数，比逐个使用哈希表插入快得多。

## 正确性说明

从石头 $j$ 出发，可能经过的权值分成三部分：

1. 起点 $j$ 自身的权值 $c_j$；
2. 第一步跳到 $2j$ 后可能经过的所有权值；
3. 第一步跳到 $j+c_j$ 后可能经过的所有权值。

除此之外不存在其他情况，所以这三部分的并集恰好就是 $S_j$。

两个后继编号都严格大于 $j$，倒序枚举保证转移时后继状态已经正确求出。由数学归纳法，所有 $S_j$ 都能被正确计算，取其中大小的最大值即为答案。

## 复杂度

每个状态最多进行两次位集求并和一次计数，每次需要 $O(n/64)$ 次机器字操作，因此：

$$
\text{时间复杂度}=O\left(\frac{n^2}{64}\right),
$$

$$
\text{空间复杂度}=O(n^2)\text{ bit}.
$$

当 $n=40000$ 时，全部位集约占

$$
\frac{40000^2}{8}\approx 191\text{ MiB},
$$

可以通过 512 MiB 的内存限制。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr int MAX_N = 40000;

// f[j] 表示从第 j 块石头出发可能遇到的权值集合。
bitset<MAX_N> f[MAX_N + 1];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> c(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> c[i];
    }

    int answer = 0;

    for (int j = n; j >= 1; --j) {
        // 当前石头本身一定可能被经过。
        f[j].set(c[j] - 1);

        if (2 * j <= n) {
            f[j] |= f[2 * j];
        }
        if (j + c[j] <= n) {
            f[j] |= f[j + c[j]];
        }

        answer = max(answer, static_cast<int>(f[j].count()));
    }

    cout << answer << '\n';
    return 0;
}
```
