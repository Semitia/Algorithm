# 题解

## 1. 把椭圆变成圆

设增幅方向与 $x$ 轴的夹角为 $\theta$，增幅倍数为 $p$，要求的半短轴为 $r$。椭圆的半长轴为 $pr$，方向为 $\theta$。

先将点 $(x,y)$ 旋转到以增幅方向为横轴的新坐标系：

$$
u=x\cos\theta+y\sin\theta,
$$

$$
v=-x\sin\theta+y\cos\theta.
$$

若椭圆中心在新坐标系中为 $(u_c,v_c)$，则一个点位于椭圆内的条件是

$$
\frac{(u-u_c)^2}{(pr)^2}+\frac{(v-v_c)^2}{r^2}\le 1.
$$

再将增幅方向压缩 $p$ 倍，令

$$
X=\frac{u}{p},\qquad Y=v,
$$

同时令 $X_c=u_c/p,Y_c=v_c$，上式就变成

$$
(X-X_c)^2+(Y-Y_c)^2\le r^2.
$$

因此，对所有输入点进行变换

$$
\boxed{
X=\frac{x\cos\theta+y\sin\theta}{p},\qquad
Y=-x\sin\theta+y\cos\theta
}
$$

以后，原问题就变成了：求这些变换后点的最小覆盖圆。圆的半径就是原椭圆的最小半短轴。

## 2. 最小覆盖圆的决定点

一个点集的最小覆盖圆由至多三个圆周上的点决定：

- 一个点时，圆的半径为 $0$；
- 两个点时，圆可以由一条直径的两个端点决定；
- 三个不共线点时，圆是它们的外接圆。

但是，不能只维护当前圆的三个决定点。当前位于圆内的历史点，在加入新点、圆心发生移动以后，也可能成为新圆的决定点。因此每次遇到圆外点时，都必须重新检查历史点。

## 3. 随机增量算法

先随机打乱所有点，然后依次加入。

假设当前圆已经覆盖 $P_0,\ldots,P_{i-1}$：

- 若 $P_i$ 在当前圆内，答案不变；
- 若 $P_i$ 在当前圆外，加入它后的新最小圆必定经过 $P_i$。

第二条可以用决定点证明。假设新最小圆不经过 $P_i$，那么决定这个圆的至多三个边界点全都属于旧点集。任何覆盖旧点集的圆都必须覆盖这些决定点，半径不可能比新圆更小，所以新圆同时也是旧点集的最小覆盖圆。它又覆盖 $P_i$，这与 $P_i$ 位于旧最小圆外矛盾。

固定 $P_i$ 在圆周上以后，将圆重置为以 $P_i$ 为圆心、半径为 $0$ 的圆，并重新扫描此前所有点。若 $P_j$ 在圆外，那么新圆还必须经过 $P_j$。

固定 $P_i,P_j$ 后，先取以 $P_iP_j$ 为直径的圆，再扫描 $P_0,\ldots,P_{j-1}$。若 $P_k$ 仍在圆外，当前答案只能改为 $P_i,P_j,P_k$ 的外接圆。

伪代码如下：

```cpp
shuffle(points);
circle = invalid_circle;

for (int i = 0; i < n; ++i) {
    if (points[i] 在 circle 内) continue;

    circle = 以 points[i] 为圆心的零圆;

    for (int j = 0; j < i; ++j) {
        if (points[j] 在 circle 内) continue;

        circle = 以 points[i]、points[j] 为直径端点的圆;

        for (int k = 0; k < j; ++k) {
            if (points[k] 在 circle 内) continue;
            circle = points[i]、points[j]、points[k] 的外接圆;
        }
    }
}
```

这并不是无条件枚举所有三元组。只有发现圆外点时，下一层循环才会执行。

## 4. 正确性

### 4.1 圆外的新点必在新圆圆周上

设旧点集为 $S$，其最小覆盖圆为 $C$，新点 $P\notin C$。假设 $S\cup\{P\}$ 的新最小圆不经过 $P$，则新圆的决定点全都来自 $S$。这些决定点单独就要求至少这么大的半径，因此新圆也是 $S$ 的最小覆盖圆。最小覆盖圆是唯一的，故它就是 $C$；但它又覆盖 $P$，与 $P\notin C$ 矛盾。因此新圆必经过 $P$。

### 4.2 三层循环分别固定边界点

- 进入第二层时，$P_i$ 已被证明必须位于圆周上；
- 第二层发现圆外点 $P_j$ 时，同理，在“圆必须经过 $P_i$”的条件下，新圆还必须经过 $P_j$；
- 第三层发现圆外点 $P_k$ 时，三个边界点已经唯一确定一个外接圆。

每次重新扫描都不会丢弃历史点，所以即使一个点以前位于圆内，它仍有机会在圆心移动后成为新的决定点。循环结束时所有已处理点均位于当前圆内，因此得到的就是最小覆盖圆。

## 5. 为什么期望复杂度是 $O(n)$

三层循环的最坏复杂度确实是 $O(n^3)$。期望 $O(n)$ 的结论依赖于开头的随机打乱。

### 5.1 外层触发重建的概率

令

$$
S_i=\{P_1,P_2,\ldots,P_i\}.
$$

注意，这里研究的是每个前缀 $S_i$ 的决定点，而不是全部 $n$ 个点的最终决定点。不同前缀的决定点可以不断变化，中途成为决定点的点全部包含在分析中。

给 $S_i$ 的最小覆盖圆选定一组至多含三个点的决定集 $B_i$。如果 $P_i\notin B_i$，那么删掉 $P_i$ 后，$B_i$ 仍然存在，并且仍能确定同一个圆。因此旧圆已经能够覆盖 $P_i$，它不会触发重建。

所以

$$
P_i\text{ 触发重建}\Longrightarrow P_i\in B_i.
$$

随机打乱后，$S_i$ 中每个点成为最后一个点 $P_i$ 的概率都是 $1/i$。因为 $|B_i|\le3$，所以

$$
\Pr(P_i\text{ 触发重建})\le\frac3i.
$$

### 5.2 一次外层重建的期望耗时

进入第二层后，$P_i$ 已经固定在圆周上，所以还需要至多两个决定点。

第二层处理到第 $j$ 个历史点时：

- 它以至多 $2/j$ 的概率触发第三层，此时要扫描此前的 $j$ 个点，耗时 $O(j)$；
- 否则只做一次是否在圆内的判断，耗时 $O(1)$。

因此第二层第 $j$ 轮的期望耗时为

$$
E[T_j]
\le
\frac2jO(j)+\left(1-\frac2j\right)O(1)
=O(1).
$$

第二层共有 $O(i)$ 轮，所以固定 $P_i$ 后，第二、第三层的总期望耗时为

$$
\sum_{j=1}^{i-1}O(1)=O(i).
$$

### 5.3 总期望耗时

外层第 $i$ 轮：

- 以至多 $3/i$ 的概率触发一次期望耗时 $O(i)$ 的重建；
- 否则只做一次是否在圆内的判断，耗时 $O(1)$。

所以

$$
E[T_i]
\le
\frac3iO(i)+\left(1-\frac3i\right)O(1)
=O(1).
$$

对所有外层循环求和：

$$
E[T]
=\sum_{i=1}^n E[T_i]
=\sum_{i=1}^nO(1)
=O(n).
$$

当 $i<3$ 或 $j<2$ 时，可以把概率上界分别严谨地写成 $\min(1,3/i)$ 和 $\min(1,2/j)$。前几个点只有常数个，不影响渐进复杂度。

因此该算法的复杂度为：

$$
\boxed{\text{期望时间 }O(n)，\quad\text{最坏时间 }O(n^3)，\quad\text{空间 }O(n)}
$$

## 6. 数值实现

- 使用 `long double` 减少旋转、缩放和外接圆计算的误差；
- 判断点是否在圆内时，应给平方距离加入相对误差；
- 三点共线或近乎共线时不能直接计算外接圆，可在三个“两点直径圆”中选择能够覆盖三点且半径最小的一个；
- 必须随机打乱输入顺序，否则不能保证期望 $O(n)$；
- 最后输出圆半径，保留三位小数。
