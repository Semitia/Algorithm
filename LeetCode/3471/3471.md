# 3471. 找出最大的几近缺失整数

给你一个整数数组 `nums` 和一个整数 `k`。

如果整数 `x` 恰好只出现在 `nums` 的一个长度为 `k` 的子数组中，那么称 `x` 是 `nums` 中的几近缺失整数。

请返回 `nums` 中最大的几近缺失整数。如果不存在这样的整数，返回 `-1`。

子数组是数组中的一个连续元素序列。

## 示例 1

```text
输入：nums = [3,9,2,1,7], k = 3
输出：7
```

解释：

- `1` 出现在两个长度为 `3` 的子数组中：`[9,2,1]` 和 `[2,1,7]`。
- `2` 出现在三个长度为 `3` 的子数组中：`[3,9,2]`、`[9,2,1]` 和 `[2,1,7]`。
- `3` 出现在一个长度为 `3` 的子数组中：`[3,9,2]`。
- `7` 出现在一个长度为 `3` 的子数组中：`[2,1,7]`。
- `9` 出现在两个长度为 `3` 的子数组中：`[3,9,2]` 和 `[9,2,1]`。

因此返回 `7`，因为它是只出现在一个长度为 `k` 的子数组中的最大整数。

## 示例 2

```text
输入：nums = [3,9,7,2,1,7], k = 4
输出：3
```

解释：

- `1` 出现在两个长度为 `4` 的子数组中：`[9,7,2,1]` 和 `[7,2,1,7]`。
- `2` 出现在三个长度为 `4` 的子数组中：`[3,9,7,2]`、`[9,7,2,1]` 和 `[7,2,1,7]`。
- `3` 出现在一个长度为 `4` 的子数组中：`[3,9,7,2]`。
- `7` 出现在三个长度为 `4` 的子数组中：`[3,9,7,2]`、`[9,7,2,1]` 和 `[7,2,1,7]`。
- `9` 出现在两个长度为 `4` 的子数组中：`[3,9,7,2]` 和 `[9,7,2,1]`。

因此返回 `3`，因为它是唯一只出现在一个长度为 `k` 的子数组中的整数。

## 示例 3

```text
输入：nums = [0,0], k = 1
输出：-1
```

解释：不存在只出现在一个长度为 `1` 的子数组中的整数。

## 提示

- `1 <= nums.length <= 50`
- `0 <= nums[i] <= 50`
- `1 <= k <= nums.length`
