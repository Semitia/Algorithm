# 2029. 石子游戏 IX

## 核心观察

石子的原始数值没有意义，只需要统计它们模 3 的余数：

```cpp
c0 = 余数为 0 的石子数量
c1 = 余数为 1 的石子数量
c2 = 余数为 2 的石子数量
```

设当前已移除石子的和模 3 为 `sum`，危险选择如下：

| `sum` | 选择后会立刻输的类型 | 安全的非零类型 |
|---|---|---|
| 0 | 0 | 1 或 2 |
| 1 | 2 | 1 |
| 2 | 1 | 2 |

因此 Alice 第一步只能选择 `1` 或 `2`。一个很容易看错的地方是：以 `1` 开局后，安全序列不是不断重复 `112`，而是：

```text
1, 1, 2, 1, 2, 1, 2, ...
```

也就是开头出现两个 `1`，后面是 `1`、`2` 交替。以 `2` 开局时完全对称：

```text
2, 2, 1, 2, 1, 2, 1, ...
```

余数为 `0` 的石子不改变 `sum`，相当于交换一次行动权。两个 `0` 又会把行动权换回来，所以 `c0` 只需要考虑奇偶性。

还要特别注意题目的耗尽规则：如果没有人凑出 3 的倍数，而石子被安全取完，仍然是 Bob 获胜。因此“被迫取危险石子”和“石子被安全取完”必须区分。

## 方法一：枚举两种首选并模拟

先完全不考虑 `0`，分别让 Alice 用 `1` 和 `2` 开局。

第一步确定后，每个状态都只有一种安全的非零选择：

- `sum == 1` 时只能安全地选择 `1`；
- `sum == 2` 时只能安全地选择 `2`。

所以不需要搜索博弈树，只需沿着唯一的安全序列向后模拟。每种首选可能得到四种结果：

1. 这种首选不存在；
2. Bob 被迫凑成 3 的倍数，Alice 获胜；
3. 石子被安全取完，Alice 失败；
4. Alice 被迫凑成 3 的倍数，Alice 失败。

当 `c0` 为偶数时，所有 `0` 可以两两抵消。只要两种首选中存在一种原本能让 Alice 获胜，答案就是 `true`。

当 `c0` 为奇数时，会留下一个有效的换手机会。Alice 要找的是一种“不考虑 `0` 时，自己最终会被迫凑成 3 的倍数”的首选，然后利用这个 `0` 交换行动顺序。若原本是因为石子被安全取完而失败，则无法扭转，因为题目始终规定这种情况由 Bob 获胜。
如果原本 Alice 就是胜利，那加上这个 `0`，肯定失败。

这种写法直接保留了完整的推理过程，对应 `2029.cpp`。

复杂度：计数和两次模拟都是线性的，总时间为 `O(n)`，额外空间为 `O(1)`。

## 方法二：推出充要条件

### `c0` 为偶数：Alice 先选少的

偶数个 `0` 不改变最终的行动关系，可以先按 `c0 == 0` 分析。

假设 `c1 <= c2`，并且两者都大于零。Alice 先选择较少的 `1`，之后的安全落子分配是：

```text
A: 1（开局）
B: 1
A: 2
B: 1
A: 2
...
```

也就是说，开局之后 Bob 消耗 `1`，Alice 消耗 `2`。因为 `c1 <= c2`，`1` 会先耗尽；此时轮到 Bob，且至少还剩一个 `2`。当前和模 3 为 `1`，Bob 只能选择 `2` 并立刻输掉。

如果 `c2 < c1`，Alice 对称地先选择 `2` 即可。因此只要两类石子都存在，Alice 就能获胜。

反过来，如果其中一类为零：

- 只有一颗非零石子时，Alice 将它取完，Bob 因耗尽规则获胜；
- 有多颗同类石子时，Alice 最终会成为被迫凑成 3 的倍数的人。

所以充要条件是：

```cpp
c1 > 0 && c2 > 0
```

### `c0` 为奇数：Alice 先选多的

两两抵消后，相当于还剩一个 `0`，它可以交换一次行动关系。此时策略与偶数情况相反：Alice 应该先选择数量较多的一类。

假设：

```text
c1 >= c2 + 3
```

Alice 先选择 `1`。如果 Bob 立即使用 `0`，安全序列为：

```text
A: 1, B: 0, A: 1, B: 2, A: 1, B: 2, ...
```

如果 Bob 不使用 `0` 而选择 `1`，Alice 就使用 `0`：

```text
A: 1, B: 1, A: 0, B: 2, A: 1, B: 2, ...
```

无论 Bob 怎样选择，后面都是 Bob 消耗较少的 `2`，Alice 消耗较多的 `1`。所有 `2` 耗尽后，安全序列最多使用 `c2 + 2` 个 `1`。

为什么必须大于 2？如果 `c1 == c2 + 2`，石子会被安全取完，按照特殊规则仍然是 Bob 获胜。只有 `c1 >= c2 + 3`，才能再留下一个 `1`，使 Bob 被迫凑成 3 的倍数。余数 `2` 更多时完全对称。

因此充要条件是：

```cpp
abs(c1 - c2) > 2
```

最终结论：

```cpp
if (c0 % 2 == 0)
    return c1 > 0 && c2 > 0;
else
    return abs(c1 - c2) > 2;
```

这种写法只进行一次计数遍历，对应 `2029_formula.cpp`。时间复杂度为 `O(n)`，额外空间为 `O(1)`。
